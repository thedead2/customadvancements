Custom Advancements gives modpack creators and server operators complete control over the Minecraft advancement system. Drop JSON files into the `customadvancements/` folder to add new advancements, remove unwanted ones, enforce progression gates, and reorder the advancement screen — no datapack required.

## How it works

<Steps>
  <Step title="Install the mod">
    Download the Forge build for Minecraft 1.16.5 and place the `.jar` file in your `mods/` folder.
  </Step>
  <Step title="Add your advancements">
    Create `.json` files inside `customadvancements/customadvancements/` in your game directory. The mod loads them on every world start.
  </Step>
  <Step title="Configure behavior">
    Edit `config/customadvancements-common.toml` to control blacklists, progression gating, recipe advancement removal, and more.
  </Step>
  <Step title="Reload in-game">
    Run `/ca reload` to apply your edits without restarting, or use `/ca generate advancement all` to export existing advancements as editable templates first.
  </Step>
</Steps>

<Note>
  This version of Custom Advancements supports **Minecraft 1.16.5** on **Minecraft Forge** only. It does not run on Fabric, Quilt, or any other loader. See the [installation page](/installation) for exact version requirements.
</Note>
