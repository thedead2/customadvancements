Custom Advancements gives modpack creators and server operators complete control over the Minecraft advancement system. Drop JSON files into the `customadvancements/` folder to add new advancements, override or remove existing ones, enforce progression gates, and customize the advancement screen — no datapack required.

## How it works

<Steps>
  <Step title="Install the mod">
    Download the Custom Advancements 4.7.5 jar and place it in your `mods/` folder alongside Minecraft Forge 40 for 1.18.2.
  </Step>
  <Step title="Add your advancements">
    Create `.json` files inside `customadvancements/customadvancements/` in your game directory. The mod loads them on every world start.
  </Step>
  <Step title="Configure behavior">
    Edit `config/customadvancements-common.toml` to control blacklists, progression gating, recipe advancement removal, and tab order.
  </Step>
  <Step title="Reload in-game">
    Run `/ca reload` to apply changes to your JSON files, textures, and language files without restarting the server.
  </Step>
</Steps>

<Note>
  This documentation covers Custom Advancements **4.7.5** for **Minecraft 1.18.2** on **Minecraft Forge**. Fabric and other Minecraft versions are not supported by this release. See the [installation page](/installation) for exact dependency versions.
</Note>
